# vcs-campusnotes--2581185-

CampusNotes is a simple note-keeping project for students, built for the Version Control System course.

## Usage

1. Clone the repository.
2. Add your notes as .txt files.
3. Commit and push your changes with Git:
   `git add .`, `git commit -m "your message"` and `git push`.
Usage: add your notes
